# Nikharta Roop logo assets

Use the appearance-specific mark so the `NR` remains readable in both themes.
The visible brand name stays as HTML text in the UI for accessibility and
sharp rendering at every screen size.

| Asset | Usage |
| --- | --- |
| `nikharta-roop-mark-light-512.png` | Website navigation in light mode |
| `nikharta-roop-mark-dark-512.png` | Website navigation in dark mode |
| `nikharta-roop-mark-light.png` | High-resolution transparent light-mode master |
| `nikharta-roop-mark-dark.png` | High-resolution transparent dark-mode master |
| `nikharta-roop-light.jpg` | Sharing or documents with a warm light background |
| `nikharta-roop-dark.jpg` | Sharing or documents with a warm dark background |

Do not stretch, crop, rotate, recolor, or place the mark on a low-contrast
background. Keep clear space around it equal to at least one lotus-petal width.
